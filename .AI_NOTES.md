## 3. AI got it wrong

Describe at least one concrete case where AI gave a plausible-looking but
incorrect, insecure, or unsafe answer. Quote the offending output and explain
how you detected it and what you did instead.

Unsafe Inventory Logic
```
const product = await getProductById(productId);

if (product.stock >= quantity) {
  await decrementStock(productId, quantity);
}
```

What was wrong with it. How you found out. What you replaced it with.

### What was wrong: 
This looked correct initially but was unsafe under concurrency.

Two requests could:

- Read the same stock value
- Both pass validation
- Both decrement inventory

### How I Detected It:
I manually reviewed the async flow and noticed:

- no transaction
- no row locking
- no atomic stock protection


### Correction Applied

Used:
- transaction scope
- SELECT ... FOR UPDATE
- atomic guarded stock updates

UPDATE products
SET stock = stock - $2
WHERE id = $1
  AND stock >= $2
